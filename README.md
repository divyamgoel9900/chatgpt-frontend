# ChatGPT-Style Frontend

A beginner-friendly, responsive ChatGPT-inspired interface made with HTML, CSS, and vanilla JavaScript.

## Features
- Dark theme with a sidebar and chat history
- Responsive layout for desktop and mobile
- New chat button
- Message composer (Enter to send, Shift+Enter for a new line)
- Suggestion chips
- Demo replies to illustrate a conversation
- Toast messages for UI-only controls

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Optional: install the **Live Server** extension in VS Code and choose **Open with Live Server**.

## Publish on GitHub
1. Create a new repository on GitHub.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site; the URL will appear on the Pages settings screen.

## Important
This is a frontend-only educational demo. It does not connect to OpenAI or the real ChatGPT service. The replies are scripted examples. Do not put secret API keys in frontend JavaScript.
